# 라니몬 디스코드 봇

## 프로젝트 개요

라니몬 디스코드 봇 서비스를 위해 개발한 Discord 봇입니다. 다양한 기능을 갖춘 커뮤니티용 봇을 목표로 했습니다.

![라니몬 봇 메인](/images/projects/rani-bot-main.png)

## 주요 기능

- **서버 관리**: 자동 역할 부여, 입장/퇴장 메시지, 채널 관리
- **유틸리티**: 날씨 예보, 계산기, 서버 정보 조회 등
- **게임 기능**: 가위바위보,slots, 서베이

![게임 기능](/images/projects/rani-bot-games.png)

- **관리자 도구**: 경고 시스템, 뮤트, 킥, 밴
- **자동화**: 스케줄링된 알림, 자동 백업

## 기술 스택

| 구분 | 기술 |
|------|------|
| Language | Node.js (JavaScript) |
| Library | discord.js |
| Hosting | VPS |
| Database | mariadb |

## 회고

Discord API 활용과 대용량 서버 관리용 봇 개발 경험을 쌓았습니다.
