# 대진표 사이트

## 프로젝트 개요

체육대회에서 사용할 대진표를 생성하고 관리할 수 있는 사이트입니다. 전공동아리 활동으로 제작했습니다.

![대진표 사이트 메인](/images/projects/bracket-main.png)

## 주요 기능

- **대진표 생성**: 참가자 수에 따른 자동 대진표 생성

![대진표 생성](/images/projects/bracket-generate.png)

- **진행 상황 관리**: 경기 결과 입력, 다음 라운드 자동 반영
- **실시간 업데이트**: 경기 결과를 즉석에서 반영

![진행 중 화면](/images/projects/bracket-progress.png)

- **결과 저장**: 대회 종료 후 결과 데이터 내보내기

## 기술 스택

| 구분 | 기술 |
|------|------|
| Backend | Python (Flask) |
| Frontend | HTML, JS, CSS |
| Database | mariadb |
| Deployment | 로컬 서버 |

## 회고

스포츠 대회 운영에 필요한 시스템을 직접 구현하며, 대진표 알고리즘에 대해 깊이 학습했습니다.
