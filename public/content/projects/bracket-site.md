# 체육대회 종합 현황 웹 서비스

## 프로젝트 소개

교내 체육대회 진행할 때 종목별 경기 결과나 학과별 점수를 한 번에 보기 어렵다고 느껴서 만든 프로젝트입니다.  
메인 화면에서는 학과별 종합 점수를 볼 수 있고, 종목별 페이지에서는 토너먼트 경기 진행 상황이나 순위형 종목 결과를 확인할 수 있게 구성했습니다.  
관리자 페이지에서는 점수 수정, 대진 생성, 순위 등록, 경기 시간 수정까지 할 수 있어서 실제 체육대회 운영에도 사용할 수 있도록 만들었습니다.

## 주요 기능

- 학과별 종합 점수와 순위 확인
- 종목별 토너먼트 / 순위형 화면 분리 제공
- 경기별 점수 수정 및 결과 반영
- 순위 등록 후 학과 총점 자동 반영
- 응원 기능을 통한 참여 요소 추가
- 관리자 로그인 기반 운영 기능 제공

## 기술 스택

- Python
- Flask
- MySQL
- SQLAlchemy
- HTML / CSS / JavaScript

## 느낀 점

단순히 화면만 만드는 게 아니라, 실제로 운영할 때 필요한 기능이 무엇인지 생각해보면서 만든 프로젝트였습니다.  
특히 토너먼트형 종목과 순위형 종목을 나눠서 처리한 부분이 가장 기억에 남았고, Flask로 관리자 기능, API, 보안 처리까지 직접 구성해보면서 웹 서비스를 조금 더 전체적으로 보는 경험을 할 수 있었습니다.
