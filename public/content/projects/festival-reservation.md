# 축제 예약 시스템

## 프로젝트 개요

축제 예약을 관리하기 위한 시스템으로, 참여 희망자가 시간대를 선택하고 예약할 수 있는 사이트입니다. 전공동아리 활동으로 제작했습니다.

![예약 시스템 메인](/images/projects/festival-main.png)

## 주요 기능

- **예약 관리**: 날짜·시간대별 예약 가능 인원 설정
- **예약 신청**: 참여자가 시간대를 선택하여 예약

![예약 신청 화면](/images/projects/festival-booking.png)

- **관리자 패널**: 예약 현황 확인, 예약 취소 처리
- **실시간 잔여석**: 남은 좌석 수 실시간 표시

![잔여석 현황](/images/projects/festival-seats.png)

## 기술 스택

| 구분 | 기술 |
|------|------|
| Backend | Python (Flask) |
| Frontend | HTML, JS, CSS |
| Database | mariadb |

## 회고

예약 시스템의 좌석 관리, 동시 예약 처리 등 실무적인 백엔드 로직을 다룰 수 있었습니다.
