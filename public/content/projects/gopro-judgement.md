# GoPro 판정 사이트

## 프로젝트 소개

코딩 문제 풀이, 정오필 기출 학습, 로드맵 기반 커리큘럼, 자유게시판, 공지사항 관리까지 하나의 플랫폼에서 해결하는 **코딩 학습 포털**입니다. Judge0 API를 활용한 실시간 코드 실행 환경부터, 연도별 세트별 정리된 정오필 퀴즈 시스템, 단계별 진도 관리까지 학습자 중심의 기능을 담았습니다.

## 주요 기능

### 1. 코딩 문제 풀이 시스템

Judge0 API를 연동하여 Python, C, C++, Java 4개 언어로 코드를 작성하고 바로 실행할 수 있습니다. 문제 난이도별 필터링, 정답률 표시, 풀이 이력 추적 기능을 제공하며, 정답 제출 시 점수가 적립됩니다.

![문제 목록](a3e07d4b-f4fa-42e2-a281-3ea2bd91dff3.png)

![문제 풀이](498e4013-a6d8-4bce-9d41-1ab9f589cf63.png)

### 2. 정오필 기출 퀴즈

국가고시 정오필 기출문제를 연도·세트·과목별로 정리하고, 퀴즈 형태로 풀이할 수 있습니다. 연도별 회차 선택 → 과목별 단원 이동 → 문항별 답안 선택 → 결과 확인까지 자연스럽게 이어지는 학습 플로우를 구현했습니다.

### 3. 로드맵 기반 커리큘럼

Python 기초, 알고리즘 등 과목별 로드맵을 제공하고, 각 단원별 강의 자료를 순차적으로 확인할 수 있습니다. 강의를 완료 표시하면 진도율이 실시간으로 반영되어 학습 현황을 한눈에 파악할 수 있습니다.

### 4. 사용자 시스템 및 점수 관리

이메일 인증, 비밀번호 재설정, 강제 비밀번호 변경 등 완전한 회원 관리 시스템을 갖추고 있습니다. 문제 풀이 정답 시 점수가 적립되며, 전체 사용자 점수 랭킹을 확인할 수 있습니다.

### 5. 관리자 패널

관리자는 회원 관리(정지, 역할 변경, 점수 조정, 비밀번호 초기화), 공지사항 관리, 자유게시판/강의/문제 CRUD를 할 수 있습니다. 모든 로그가 기록되어 보안 이벤트 추적도 가능합니다.

### 6. 보안 및 인프라

- **CSRF / XSS 방지**: Flask-WTF CSRFProtect + Jinja2 자동 이스케이프 + Talisman CSP
- **비밀번호 해싱**: Argon2 (time_cost=2, memory_cost=64MB)
- **스팸 방지**: Cloudflare Turnstile (로그인 5회 실패 시)
- **정적 리소스 차단**: 민감한 경로/파일 접근 자동 차단
- **로그 필터링**: DB URI, 이메일 주소 등 민감 데이터 마스킹

## 기술 스택

| 구분 | 기술 |
|------|------|
| **Framework** | Flask 3.x + Flask-SQLAlchemy |
| **DB** | MySQL (PyMySQL) |
| **Frontend** | HTML/CSS/JavaScript, Jinja2 템플릿, Quill 에디터 |
| **Code Execution** | Judge0 API (실시간 코드 실행) |
| **Security** | Flask-WTF, Flask-Talisman, Argon2, Cloudflare Turnstile |
| **Email** | SMTP (async thread 전송) |
| **Deployment** | Gunicorn, VPS |
| **Authentication** | 세션 기반 로그인 + 세션 토큰 갱신 (세션 고정 공격 방지) |

## 느낀 점

단순한 CRUD 웹사이트가 아닌, **실시간 코드 실행, 기출 학습, 진도 관리** 등 복합적인 학습 시나리오를 하나의 시스템으로 통합하며 백엔드의 설계 역량을 키울 수 있었습니다. 특히 Judge0 API 연동을 통해 외부 서비스와 RESTful 통신을 처리하는 방법을 체득했고, 보안 취약점을 스스로 분석하고 보완하는 과정에서 웹 보안에 대한 이해도 한층 깊어졌습니다. 코드의 가독성과 유지보수성을 위해 모듈 블루프린트 단위로 분리하고, 템플릿/정적파일/CSS를 체계적으로 구성하여 확장성 있는 구조를 설계했습니다.
