# GoPro 저지먼트 사이트

## 프로젝트 개요

코드 문제를 풀어볼 수 있는 온라인 저지(문제 풀이) 사이트입니다. 알고리즘 학습과 코딩 테스트 연습을 위해 개발했습니다.

![저지먼트 사이트 메인](/images/projects/gopro-judgement-main.png)

## 주요 기능

- **문제 은행**: 다양한 난이도의 코딩 문제 제공
- **코드 제출 & 채점**: 코드 실행 및 정답 여부 자동 채점

![코드 제출 화면](/images/projects/gopro-judgement-submit.png)

- **랭킹 시스템**: 점수 기반 사용자 랭킹
- **사용자 대시보드**: 내 제출 내역, 맞은 문제 통계

![랭킹 화면](/images/projects/gopro-judgement-ranking.png)

## 기술 스택

| 구분 | 기술 |
|------|------|
| Backend | Python (Flask) |
| Frontend | HTML, JS, CSS |
| Database | MySQL |
| Judge | Judge0 |
| Hosting | AWS |

## 회고

코드 실행 환경을 안전하게 격리하는 방법을 학습하고, 웹과 백엔드를 연결하는 풀스택 개발을 경험했습니다.
