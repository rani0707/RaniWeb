# HOOK 인트라넷

## 프로젝트 소개

HOOK 인트라넷은 Discord 인증을 기반으로 팩션 인원을 관리하고, 호출 기록·거래 장부·공동계좌·블랙리스트·휴가·사업권 감시까지 한곳에서 운영할 수 있도록 만든 웹 기반 관리 시스템입니다. 단순한 조회용 대시보드에 그치지 않고, Discord 봇과 백엔드 서버를 연동해 게임 내 활동 데이터를 실시간으로 수집하고 웹 화면에서 바로 확인할 수 있도록 구성했습니다.

## 주요 기능

- **Discord 기반 인증 및 권한 관리**: Discord OAuth 로그인과 승인 절차를 통해 인원을 관리하고, 관리자·간부·일반 직책별로 접근 권한을 분리했습니다.
- **실시간 대시보드 및 호출 분석**: 팩션원 수, 블랙리스트 현황, 월간 거래액, 서버 상태, 호출 추이 등을 차트와 통계 카드로 시각화했습니다.
- **거래 장부 및 공동계좌 관리**: 아이템 거래 내역, 정산 상태, 자동 완료 처리, 공동계좌 입출금 기록을 연동해 운영 흐름을 한 화면에서 관리할 수 있게 했습니다.
- **운영 관리 기능 통합**: 공지 템플릿, 휴가 관리, 블랙리스트 관리, 팩션 활동 기록, 사업권 거래 감시 기능을 통합해 반복적인 수작업을 줄였습니다.
- **실시간 이벤트 반영**: Socket.IO와 Discord 봇 연동으로 새로운 거래, 활동 기록, 블랙리스트 변경 사항을 실시간으로 반영하도록 구현했습니다.

## 기술 스택

| 구분 | 기술 |
|------|------|
| Frontend | React, Vite, Axios, Recharts, Socket.IO Client |
| Backend | Node.js, Express, Socket.IO |
| Database | MySQL |
| Auth | Discord OAuth, JWT, Passport |
| Bot / Integration | Discord.js, Axios, WebSocket |
| Infra / ETC | node-cron, Helmet, CORS |

## 느낀 점

이번 프로젝트는 단순한 웹 페이지 제작보다, **게임 운영 데이터를 실제 업무 도구처럼 구조화하는 경험**에 더 가까웠습니다. Discord 봇, 웹 프론트엔드, 백엔드 API, 데이터베이스를 하나의 흐름으로 연결하면서 실시간 동기화와 권한 처리, 자동화 로직을 함께 설계하는 방법을 배울 수 있었습니다.

특히 운영자가 자주 확인하는 정보들을 한 화면에 정리하고, 반복적으로 처리하던 기록 업무를 자동화하면서 **"기능을 만드는 것"을 넘어 "실제로 쓰이는 관리 도구를 만든다"는 감각**을 얻은 프로젝트였습니다.
