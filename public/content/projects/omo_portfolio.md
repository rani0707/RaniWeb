# 오모오모

## 프로젝트 소개
YOLO 기반 객체 탐지를 활용해 이미지와 영상에 자동 모자이크를 적용하고, 회원 인증과 실시간 채팅 기능까지 함께 제공한 웹 서비스입니다. 사용자는 로그인 후 남은 사용량을 확인하고, 업로드한 파일의 처리 결과를 바로 확인하거나 채팅방에서 다른 사용자와 공유할 수 있도록 구성했습니다.

## 주요 기능
- 회원가입, 로그인, 로그아웃 등 세션 기반 사용자 인증
- 프로필 페이지에서 마지막 로그인 정보와 남은 사용 횟수 확인
- 이미지 및 영상 업로드 후 YOLO 기반 객체 탐지와 자동 모자이크 처리
- 처리된 파일을 포함한 메시지를 실시간 채팅으로 공유
- 업로드 파일 다운로드와 영상 스트리밍 지원

## 기술 스택
| 구분 | 기술 |
|------|------|
| Backend | Python, Flask, Flask-SocketIO |
| Database | MySQL, SQLAlchemy |
| AI / CV | Ultralytics YOLO, OpenCV |
| Frontend | HTML, CSS, JavaScript |
| Feature | File Upload, Session Auth, Real-time Chat |

## 느낀 점
이번 프로젝트를 통해 YOLO 같은 AI 기능을 단순히 붙이는 것에서 끝나는 것이 아니라, 로그인, 사용량 관리, 파일 업로드, 결과 확인, 실시간 공유까지 하나의 서비스 흐름으로 연결하는 과정이 중요하다는 점을 배웠습니다. 특히 이미지뿐 아니라 영상 처리까지 고려하면서, AI 기능을 실제 사용자가 체감할 수 있는 웹 서비스 형태로 구현하는 경험을 쌓을 수 있었습니다.
